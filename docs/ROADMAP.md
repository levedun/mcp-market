# Roadmap / бэклог

Идеи «что ещё можно сделать», чтобы не потерять. Это не обязательства и не сроки.
Готовый к работе пункт лучше завести как GitHub Issue и сюда поставить ссылку или вычеркнуть.

## Инфра и CI

- [ ] После split CI (`unit` / `mcp` / `browser` + aggregator `ci`): в настройках ветки required check = **`Test / ci`**, не старый `Test / test`.
- [ ] PRы только в `levedun/mcp-market` (upstream remote снят намеренно).

## Каталог (SQLite + витрина)

- [ ] Бэкфилл `category_path`: для строк без категорий вызвать `*_details` / `*_card` и дописать путь (не затирать уже заполненное).
- [ ] Экспорт `product_snapshots` → ClickHouse / аналитика (в коде уже заложена схема «текущее состояние + история»).
- [ ] Витрина: фильтр по площадке, текстовый поиск, график цены по snapshots.
- [ ] При старте MCP с `MARKET_CATALOG=1` логировать путь БД и `enabled`; при `≠1` — одну строку «catalog off».

## MCP / Windows ops

- [ ] Защита от двух процессов `src/index.js`: при старте предупреждать или отказываться, если уже есть живой инстанс с тем же профилем/БД.
- [ ] Документировать: после смены `env` в `mcp.json` нужен полный рестарт MCP (иначе Cursor может держать старый процесс без `MARKET_CATALOG`).
